| 파일명 | 위치 | 권장 크기 | 비고 |
|---|---|---|---|

| `stats-bg.jpg` | 실적(30,000건) 섹션 배경 | 1920×600 | 책상·손 사진, 네이비 오버레이가 CSS로 덮임 |

| `lawyers.png` | 무료 법률 상담 안내 – 변호사 3인 | 1800×1120 | 배경 투명(누끼) PNG |

> 아이콘(실적·장점·진행과정·전화)은 모두 인라인 SVG로 구현되어 있어 별도 이미지가 필요 없습니다.
